# Changelog

## 1.0.0 — 2026-09-25

- Added a standalone KSP 1.12.5 SOI visualizer for Flight Map View and the Tracking Station.
- Added a selectable orbit-aligned ring and body-fixed spherical grid at the KSP SOI radius.
- Added animated, curved entry and exit waves at predicted patched-conic transitions, including maneuver plans and later escapes.
- Added independent boundary and wave switches, orbit-segment edge colors, a configurable cyan wave center, and persistent in-game settings.
- Added an English application launcher panel, source build script, and isolated trajectory and geometry checks.

The installed KSP assembly build and 46 isolated checks pass. Some 1.0.0 visual combinations and compatibility with modded planetary systems still await in-game validation.
